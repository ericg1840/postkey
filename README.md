# PostKey

A tool for building branded real estate social posts — upload property photos,
pick a layout, and export a finished image ready to post.

Three layout styles:
- **Bold Band** — photo with an on-photo headline, address strip, and a contact band (logo + circular headshot + pink badge)
- **Just Listed** — hero photo, centered headline, stats row (beds/baths/sqft/price), and a strip of arched photos
- **Collage** — offset photo collage with a bold top headline and a signature-style sign-off

## Live site

Once GitHub Pages is enabled for this repo (Settings → Pages → Source: GitHub Actions),
this auto-builds and deploys on every push to `main`.

## Local development

```
npm install
npm run dev
```

## Build

```
npm run build
```
